# Планировщик задач

Веб-приложение для планирования задач пользователя. Это итоговый проект курса Golang для начинающих от Яндекса.

Планировщик позволяет создавать задачи на определенную дату, редактировать их, отмечать выполненными и удалять.

В качестве БД используется SQLite. Веб-интерфейс был готовый, серверную часть реализовал на Go.

## Что умеет планировщик

- Создавать новые задачи;
- Просматривать список ближайших задач;
- Получать информацию по отдельной задаче;
- Редактировать задачи;
- Удалять задачи;
- Отмечать задачи как выполненные;
- Автоматически переносить периодические задачи на следующую дату;
- Хранить задачи в SQLite;

## Выполненные задания со звёздочкой

Реализовано задание со звёздочкой `NextDate`: расширенная обработка правил повторения задачи, а также повтор задачи по дням недели и дням месяца.

Поиск задач, аутентификация и создание Docker-образа не реализованы.

## Структура планировщика

Каждый процесс планировщика разбит на отдельные файлы, чтобы было удобнее работать с ними.

- `pkg/api` - HTTP-обработчики API и логика расчёта дат;
- `pkg/db` - работа с БД (SQLite);
- `pkg/server` - запуск сервера;
- `web` - файлы веб-интерфейса (даны заранее)
- `tests` - тесты проекта (даны заранее)

## Как запустить планировщик

Для запуска потребуется GO на вашем ПК. Клонируйте репозиторий и в терминале выполните (Bash): go run .

Default порт для запуска сервера "7540"

В браузере вставьте ссылку "http://localhost:7540" (без кавычек)

!!!При первом запуске файл БД `scheduler.db` создаётся автоматически!!!

## База данных (БД)

В проекте использовался SQLite, по умолчанию это файл `scheduler.db`

!!!БД файл был добавлен в папку `.gitignore` и не сохраняется в репозитории для удобства.

## Описание реализованных API

-`GET /api/nextdate` - расчёт следующей даты;
-`POST /api/task` - создание одной задачи;
-`GET /api/task` - получение задачи; 
-`PUT /api/task` - изменение задачи;
-`DELETE /api/task` - удаление задачи;
-`GET /api/tasks` - получение списка задач;
-`POST /api/task/done` - отметка задачи как выполненной;
